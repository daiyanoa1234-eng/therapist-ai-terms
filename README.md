# IT・生成AI基礎用語チェック

「セラピストのためのCodex超入門」用の、IT・生成AI基礎用語の学習＋確認テストWebアプリです。
スマホでの利用を想定しています。

## 内容

- 6セクション × 10語（計60語）
  1. パソコンとインターネットの基本
  2. サービスをつなぐ仕組み
  3. 生成AIのしくみ
  4. AIを使いこなすコツ
  5. Codexと開発の基本
  6. 医療現場でのAI安全ルール
- 各セクション：用語カードで学習 → 確認テスト（ランダム5問・4択）
- 総合テスト：全60語からランダム10問、8問以上で合格 → 修了証を表示
- 結果画面で、間違えた用語の解説を表示
- 記録は保存しません（ログイン不要、ページを閉じるとリセット）

## ファイル構成

```
index.html      画面の土台
css/style.css   見た目
js/data.js      用語データと出題設定（内容の修正はここだけ）
js/app.js       画面の切り替え・テストの動き
```

## 用語や設定を変えるとき

`js/data.js` だけを編集します。

- 用語を追加：該当セクションの `terms` に `{ t, r, d, x }` を1行追加
- 問題数・合格ライン：ファイル末尾の `QUIZ_CONFIG` を変更
- `d`（意味）には用語そのものを書かないでください（問題の答えがバレるため）

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成（Public）
2. このフォルダの中身をすべてアップロード（`index.html` がリポジトリ直下に来るように）
3. リポジトリの **Settings → Pages** を開く
4. **Source** を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
5. 1〜2分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` が公開URL

スライドに載せるQRコードは、このURLから作成してください。

## 手元で確認する

`index.html` をブラウザで開くだけで動きます（サーバー不要）。
